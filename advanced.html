📝 SECTION 1: HTML FORMS

What is a Form?

A form is like a digital paper form. It collects information from users and sends data to a server. Think of registration pages, login pages, contact forms - all use HTML forms.

Basic Form Structure:
<form action="/submit" method="POST">
action = where to send the data (server URL)
method = how to send it (GET or POST)

🎯 Complete Form Example with All Input Types

⚠️ Important Notes:
• Always use <label> with for attribute matching input's id
• Use required attribute for mandatory fields
• placeholder shows hint text inside input
• Radio buttons with same name = only one can be selected
• Checkboxes can have multiple selections

📊 SECTION 2: HTML TABLES

What is a Table?

Tables display data in rows and columns, like a spreadsheet. Used for structured data like student marks, product lists, schedules, etc.

Table Structure:
<table> - Creates the table
<thead> - Header section
<tbody> - Body section
<tfoot> - Footer section
<tr> - Table row
<th> - Header cell (bold, centered)
<td> - Data cell (normal text)

🚀 SECTION 3: ADVANCED HTML TAGS

🏗️ Semantic HTML5 Tags (Page Structure)

Semantic tags describe their meaning clearly. Better for SEO and accessibility.

<header>

Top section of page containing logo, navigation, site title

<nav>

Navigation menu with links

<main>

Main content area of page (unique per page)

<section>

Thematic grouping of content

<article>

Self-contained content (blog post, news article)

<aside>

Sidebar content, related info

<footer>

Bottom section with copyright, contact info

<figure>

Image with caption

🎬 Multimedia Tags

1. Video Tag

<video width="320" height="240" controls autoplay muted loop>
  <source src="movie.mp4" type="video/mp4">
  Your browser doesn't support video.
</video>

Attributes:
• controls - Shows play/pause buttons
• autoplay - Starts automatically
• muted - No sound
• loop - Repeats video
• poster - Thumbnail image before playing

2. Audio Tag

<audio controls autoplay loop>
  <source src="song.mp3" type="audio/mpeg">
  Your browser doesn't support audio.
</audio>

3. Iframe Tag (Embed Websites/YouTube)

<iframe src="https://www.youtube.com/embed/VIDEO_ID" width="560" height="315"></iframe>
